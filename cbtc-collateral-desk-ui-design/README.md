# CBTC Collateral Desk UI

Two static pages based on the supplied project scope and redesign:
- `landing/` — public product landing page
- `desk/` — interactive Credit Officer Console demo

Open `landing/index.html` in a browser, then use **Launch the Desk** to open the console.

The console is a front-end demo only; its buttons simulate workflow state and do not connect to Canton, Grofty, DecMan, or a real ledger.
